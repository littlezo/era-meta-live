## 问题分析
当前弹幕消息功能存在问题，主要是因为：
1. `messageManager.ts` 中直接实现了 Tauri 事件监听，没有利用现有的 `platformApiService`
2. `platformApiService` 中缺少统一的消息类型定义和订阅机制
3. 消息处理逻辑分散，不便于维护和扩展

## 修复方案
1. **修改 `src/platforms/common/platformApiService.ts`**：
   - 添加统一的消息类型定义 `UnifiedMessage`
   - 添加消息订阅方法 `subscribeToMessages`，封装 Tauri 的 `listen` 函数
   - 提供取消订阅机制

2. **修改 `src/components/player/messageManager.ts`**：
   - 使用 `platformApi.subscribeToMessages` 替代直接的 Tauri 事件监听
   - 简化消息处理逻辑
   - 利用 `platformApi.startMessageListener` 和 `platformApi.stopMessageListener` 管理消息监听

3. **修改 `src/components/player/types.ts`**：
   - 确保 `Message` 类型与 `UnifiedMessage` 兼容

## 预期效果
修复后，前端将能够：
1. 通过统一的 `platformApi.subscribeToMessages` 方法订阅弹幕消息
2. 接收所有平台的统一格式消息
3. 方便地取消消息订阅
4. 处理消息显示和存储

## 关键实现细节
1. **在 `platformApiService.ts` 中**：
   ```typescript
   // 统一的消息类型定义
   export interface UnifiedMessage {
     id: string;
     room_id: string;
     user: string;
     content: string;
     user_level?: number;
     fans_club_level?: number;
     type?: string;
     color?: string;
   }

   // 消息订阅方法
   public async subscribeToMessages(
     callback: (message: UnifiedMessage) => void,
     roomId?: string
   ): Promise<() => void> {
     try {
       const unlisten = await listen<UnifiedMessage>('message', (event) => {
         const message = event.payload;
         if (message && (!roomId || message.room_id === roomId)) {
           callback(message);
         }
       });
       return unlisten;
     } catch (error) {
       console.error('Failed to subscribe to messages:', error);
       throw error;
     }
   }
   ```

   ```typescript

     // 处理消息
   }, roomId);
   ```
