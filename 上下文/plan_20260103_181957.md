# 平台代码统一整合计划

## 1. 整合目标
- 统一整合所有平台代码，不再区分平台
- 移除所有特定平台的类型定义，统一由 SDK 提供
- 确保前端只通过统一的接口与后端交互
- 简化 `src/platforms` 目录结构，只保留必要的通用代码

## 2. 整合范围
### 2.1 目录结构调整
- 保留 `src/platforms/common/` 目录，简化其内容
- 删除所有平台特定目录：`bilibili/`, `douyin/`, `douyu/`, `huya/`
- 确保所有平台特定逻辑已迁移到后端 `src-tauri/platforms`

### 2.2 文件整合
- 保留并简化 `platformApiService.ts`，作为前端与后端的唯一交互接口
- 移除所有平台特定的 API 调用和数据处理代码
- 移除所有平台特定的类型定义，只保留必要的通用类型
- 简化 `types.ts`，只保留前端必要的通用类型

### 2.3 类型定义处理
- 移除所有平台特定的类型定义
- 确保前端使用的所有类型都来自统一的 SDK
- 更新类型导入，确保使用正确的类型来源
