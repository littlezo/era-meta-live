# 修复重构后存在的问题

## 问题分析

1. **主播状态异常**
   - 在 `FollowsList/index.vue` 中，`refreshList` 函数只对 `huya` 和 `bilibili` 平台调用了 `fetchRoomInfo` API
   - `douyu` 和 `douyin` 平台的刷新函数被注释掉，导致状态无法更新
   - 关注列表中的主播状态显示异常

2. **点击直播无法进入详情**
   - 可能是路由配置或跳转逻辑问题
   - 需要检查 `goToPlayer` 函数和 `selectAnchor` 函数的实现

## 解决方案

1. **修复主播状态刷新**
   - 更新 `FollowsList/index.vue` 中的 `refreshList` 函数，为所有平台使用统一的 `fetchRoomInfo` API
   - 移除平台特定的刷新函数，使用统一的 API 调用

2. **检查直播详情跳转**
   - 检查 `StreamerList/index.vue` 中的 `goToPlayer` 函数
   - 确保路由配置正确，`Player` 路由存在且能处理 `roomId` 和 `platform` 参数
   - 检查 `followStore` 中的 `selectAnchor` 函数

## 预期效果
- 所有平台的主播状态都能正确更新
- 点击直播能正常进入主播详情页
- 关注列表中的主播状态显示正常
