## 五、技术栈

- Rust：实现统一接口和平台工厂
- TypeScript/Vue：实现前端统一 API 服务和组件
- async-trait：支持异步 Trait 实现
- reqwest：处理 HTTP 请求
- tokio：异步运行时
- tauri：桌面应用框架（主应用使用）
