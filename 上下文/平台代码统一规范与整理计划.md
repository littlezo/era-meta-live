# 平台代码统一规范与整理计划

## 1. 概述

根据项目需求，需要对 `/Volumes/Data/project/era-meta-live` 和 `/Volumes/Data/project/era-meta-live/src-tauri` 进行全面整理，解决以下问题：
- 命令混乱、结构混乱、风格不统一
- 日志实现不统一
- HTTP客户端混用（直接使用`reqwest`和`shared::http_client::HttpClient`）
- 缺少完整的日志记录
- 移除不必要的 `xxx_with_raw` 函数

## 2. 主要任务

### 2.1 统一日志实现

- **文件**：所有平台相关文件
- **任务**：确保所有平台使用统一的日志系统
  - 统一使用 `shared::logger::Logger` 进行日志记录
  - 确保日志初始化正确
  - 统一日志格式和级别
  - 确保关键操作都有日志记录
- **检查点**：
  - 每个平台的 `lib.rs` 都正确初始化了日志
  - 所有模块都使用了统一的 `Logger` 实例
  - 关键函数调用都有适当的日志记录

### 2.2 统一HTTP客户端使用

- **文件**：所有平台相关文件
- **任务**：确保所有平台统一使用 `shared::http_client::HttpClient`
  - 替换直接使用 `reqwest::Client` 的地方
  - 确保正确配置HTTP客户端（直连或代理）
  - 统一HTTP请求处理方式
- **检查点**：
  - 移除所有直接使用 `reqwest::Client` 的代码
  - 所有HTTP请求都通过 `shared::http_client::HttpClient` 发送
  - 统一错误处理方式

### 2.3 移除不必要的 `xxx_with_raw` 函数

- **文件**：`/src-tauri/src/platform_commands.rs`
- **任务**：移除所有带有 `_with_raw` 后缀的函数，包括：
  - `fetch_live_list_with_raw`
  - `fetch_room_info_with_raw`
  - `get_stream_url_with_raw`
  - `fetch_streamer_info_with_raw`
  - `search_rooms_with_raw`
- **理由**：根据历史上下文，这些函数不再需要，且 `_with_raw` 参数已被忽略

### 2.4 统一命令命名规范

- **文件**：所有平台相关文件
- **任务**：确保所有命令函数命名一致，遵循以下规则：
  - 使用清晰、描述性的命名
  - 避免平台特定前缀（如 `fetch_bilibili_live_list` → `fetch_live_list`）
  - 统一使用 `fetch_` 前缀获取数据，`get_` 前缀获取资源
- **检查点**：
  - 所有平台的函数命名一致
  - 没有平台特定前缀
  - 函数命名遵循统一规则

### 2.5 修复编译警告

- **文件**：所有平台相关文件
- **任务**：
  - 修复未使用的导入
  - 修复未使用的宏定义
  - 修复命名规范问题
  - 处理其他编译警告
- **检查点**：
  - `cargo check` 无警告
  - 所有代码符合Rust命名规范
  - 无未使用的导入或变量

## 3. 实施步骤

### 步骤 1：统一日志实现

1. 检查每个平台的日志使用情况
2. 确保每个平台都使用 `shared::logger::Logger`
3. 添加缺失的日志记录
4. 统一日志格式和级别

### 步骤 2：统一HTTP客户端使用

1. 检查每个平台的HTTP客户端使用情况
2. 替换直接使用 `reqwest::Client` 的代码
3. 确保所有HTTP请求通过 `shared::http_client::HttpClient` 发送
4. 统一HTTP错误处理

### 步骤 3：移除不必要的 `xxx_with_raw` 函数

1. 检查 `platform_commands.rs` 中的所有 `xxx_with_raw` 函数
2. 确认这些函数没有被其他代码引用
3. 移除这些函数

### 步骤 4：修复编译警告

1. 运行 `cargo check` 查看所有警告
2. 逐一修复每个警告
3. 再次运行 `cargo check` 确认所有警告已修复

### 步骤 5：验证所有平台功能

1. 编译整个项目
2. 确保所有平台都能正常注册
3. 测试基本功能（获取直播间信息、直播流URL等）

## 4. 预期成果

- 统一的日志实现，所有平台使用相同的日志系统
- 统一的HTTP客户端使用，不再混用 `reqwest` 和 `shared::http_client::HttpClient`
- 移除了不必要的 `xxx_with_raw` 函数
- 统一的命令命名规范
- 无编译警告
- 所有平台功能正常
