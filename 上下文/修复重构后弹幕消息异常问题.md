## 问题分析
重构后弹幕消息异常的根本原因是：
1. 后端 `platform_commands.rs` 中正确使用 `app_handle.emit("message", message)` 发送弹幕消息
2. 前端 `messageManager.ts` 中的 `startCurrentMessageListener` 函数缺少实际的消息监听逻辑
3. 前端没有使用 `listen` 函数从 Tauri 监听 "message" 事件

## 修复方案
1. **修改 `src/components/player/messageManager.ts`**：
   - 添加 Tauri 事件监听逻辑
   - 使用 `invoke` 调用后端 `start_message_listener` 命令
   - 使用 `listen` 监听 Tauri "message" 事件
   - 将收到的消息添加到消息列表中
   - 确保返回正确的停止函数

2. **修改内容**：
   - 从 `@tauri-apps/api/core` 导入 `invoke`
   - 从 `@tauri-apps/api/event` 导入 `listen`
   - 在 `startCurrentMessageListener` 函数中实现完整的消息监听逻辑
   - 确保 `stopCurrentMessageListener` 函数调用后端 `stop_message_listener` 命令

## 预期效果
修复后，前端将能够正确：
1. 调用后端启动消息监听
2. 接收 Tauri 发送的 "message" 事件
3. 处理并显示弹幕消息
4. 在需要时停止消息监听

## 关键代码位置
- `src/components/player/messageManager.ts`：核心修复文件
- `src-tauri/src/platform_commands.rs`：后端消息发送逻辑（已正确实现）
- `src/components/player/index.vue`：调用消息管理函数的组件（无需修改）
