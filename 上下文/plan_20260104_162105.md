### 问题分析
从终端输出中看到错误：`日志系统初始化失败: attempted to set a logger after the logging system was already initialized`

### 根本原因
1. 在`src/main.rs`中，第32行先调用了`init_logger()`初始化自定义日志系统
2. 然后在第39行添加了`tauri_plugin_log::Builder::new().build()`插件
3. `tauri_plugin_log`插件会尝试再次初始化日志系统，导致冲突
4. 最终导致应用崩溃：`PluginInitialization("log", "attempted to set a logger after the logging system was already initialized")`

### 解决方案
移除`tauri_plugin_log`插件，继续使用我们自己实现的日志系统。

### 具体修改步骤
1. 删除`src/main.rs`中第15行的`use tauri_plugin_log;`导入
2. 删除第39行的`.plugin(tauri_plugin_log::Builder::new().build())`插件配置
3. 其他配置保持不变

### 预期效果
修复后，运行`pnpm tauri dev`命令时，日志系统将只由`init_logger()`初始化一次，不会发生冲突，应用可以正常启动。
