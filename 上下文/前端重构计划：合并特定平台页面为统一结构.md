# 前端重构计划：合并特定平台为统一结构

## 目标
将现有的平台特定页面合并为统一结构，通过路由参数区分平台，完全依赖统一API，同时统一src/platforms目录结构。

## 重构内容

### 1. 统一页面组件
- 修改现有的 `PlayerView.vue`，使其支持动态平台参数
- 创建统一的 `HomeView.vue`，替代所有平台特定的HomeView

### 2. 调整路由配置
- 修改路由为 `/home/:platform` 替代 `/douyu`, `/bilibili` 等固定路径
- 修改播放器路由为 `/player/:platform/:roomId`
- 设置默认路由 `/home/douyin`

### 3. 统一API服务
- 更新 `apiService.ts`，移除对特定平台API的依赖
- 确保所有API调用都使用统一的invoke方式
- 确保API服务能处理所有平台的请求

### 4. 统一Platforms目录结构
- 移除或重构平台特定的API文件
- 确保所有平台相关的代码都遵循统一的结构
- 保留平台特定的辅助函数，但通过统一接口调用

### 5. 移除冗余页面
- 删除所有平台特定的HomeView和PlayerView

### 6. 测试和验证
- 确保所有平台的首页和播放器都能正常工作
- 确保分类选择、主播列表、关注功能正常

## 实现步骤

1. **创建统一HomeView.vue**：
   - 支持动态平台参数
   - 使用统一API获取分类数据
   - 向子组件传递正确的平台参数

2. **修改PlayerView.vue**：
   - 添加platform作为props
   - 使用统一API获取流信息
   - 支持动态平台的关注功能

3. **更新apiService.ts**：
   - 移除对特定平台API的导入
   - 统一使用invoke调用后端API
   - 确保所有平台的API调用都通过统一接口

4. **更新路由配置**：
   - 添加动态路由
   - 移除平台特定路由
   - 设置默认路由

5. **重构Platforms目录**：
   - 保留必要的平台特定配置和辅助函数
   - 移除不再需要的平台特定API文件
   - 确保目录结构统一

6. **测试各平台功能**：
   - 测试首页访问
   - 测试播放器加载
   - 测试分类和主播列表
   - 测试关注功能

7. **清理冗余代码**：
   - 删除平台特定页面
   - 确保没有引用错误

## 预期结果
- 代码冗余大幅减少
- 新增平台时无需创建新页面
- 完全依赖统一API，简化前端逻辑
- 统一的目录结构和代码风格
- 清晰的路由结构
