# 前端重构计划

## 重构目标
1. 整合所有平台特定的代码，统一前端入口
2. 通过路由参数确认调用平台，抹平平台差异
3. 移除前端特定平台信息，改为统一调用
4. 将所有 '@tauri-apps/**' 相关的 API 整合进 invoke/index.ts 统一调用

## 重构步骤

### 1. 路由配置修改
- 修改 `src/router/index.ts`，将所有平台特定路由整合为统一路由
- 首页路由：`/` -> 支持 `platform` 参数，默认为 douyin
- 播放器路由：`/player/:platform/:roomId` -> 统一播放器入口

### 2. 统一入口页面创建
- **创建 `src/pages/HomeView.vue`**：替换所有 `xxxHomeView.vue`
- **修改 `src/pages/PlayerView.vue`**：支持动态平台切换
- 移除所有平台特定的页面组件：`BilibiliHomeView.vue`, `BilibiliPlayerView.vue`, `DouyinHomeView.vue`, `DouyinPlayerView.vue`, `DouyuHomeView.vue`, `DouyuPlayerView.vue`, `HuyaHomeView.vue`, `HuyaPlayerView.vue`

### 3. 组件整合
- **重命名 `CommonStreamerList` 为 `StreamerList`**：统一主播列表组件
- 修改 `StreamerList` 组件，使其支持动态平台切换
- 整合平台特定的 composables，创建统一的数据获取方式

### 4. 平台特定代码整合
- 分析 `src/platforms/` 下的代码，提取通用逻辑
- 创建统一的平台 API 调用层，处理不同平台的数据格式差异
- 移除前端特定平台信息，改为通过配置或枚举统一管理

### 5. Tauri API 统一
- **创建 `src/invoke/index.ts`**：整合所有 `@tauri-apps/**` 相关的 API 调用
- 定义统一的函数接口，隐藏平台差异

### 6. 资源和数据文件处理
- 保留平台特定的资源文件（如图片、字体）
- 整合平台特定的分类数据，创建统一的分类管理

### 7. 代码清理
- 移除无用的平台特定代码和文件
- 确保所有导入路径正确
- 运行测试，确保重构后的代码正常工作

## 技术实现要点

### 1. 路由配置
```typescript
// 修改后的路由配置示例
const router = createRouter({
  history: createWebHistory(),
  routes: [
    { path: '/settings', name: 'Settings', component: SettingsView },
    { path: '/', name: 'Home', component: HomeView, props: { platform: 'douyin' } },
    { path: '/:platform', name: 'HomeWithPlatform', component: HomeView, props: true },
    { path: '/player/:platform/:roomId', name: 'Player', component: PlayerView, props: true }
  ]
})
```

### 2. 统一 HomeView 组件
```vue
<template>
  <div class="home-view">
    <div class="content">
      <div class="left-panel" v-if="categoriesData.length">
        <CommonCategory 
          :categoriesData="categoriesData"
          @category-selected="onCategorySelected" 
        />
      </div>
      <div class="right-panel">
        <StreamerList
          :selectedCategory="selectedCategory"
          :categoriesData="categoriesData"
          :platformName="platform"
          :playerRouteName="'Player'"
        />
      </div>
    </div>
  </div>
</template>
```

### 3. 统一 PlayerView 组件
```vue
<template>
  <div class="player-view">
    <MainPlayer 
      v-if="roomId" 
      :platform="platform" 
      :room-id="roomId" 
      :is-followed="isFollowed" 
      @follow="handleFollow" 
      @unfollow="handleUnfollow" 
      @close-player="handleClosePlayer" 
    />
    <div v-else>
      <p>无效的房间ID。</p>
    </div>
  </div>
</template>
```

### 4. Tauri API 统一调用
```typescript
// src/invoke/index.ts
import { invoke } from '@tauri-apps/api'

export const tauriInvoke = {
  // 统一调用 Tauri 命令
  async getStreamUrl(platform: string, roomId: string) {
    return invoke('get_stream_url', { platform, roomId })
  },
  // 其他 Tauri API 调用...
}
```

## 优先级
1. 先重构核心功能，确保正常使用
2. 再移除无用的代码和文件
3. 最后进行优化和测试

## 预期效果
- 前端代码更加简洁，易于维护
- 支持动态切换平台，无需修改代码
- 统一的 API 调用方式，降低平台差异带来的复杂性
- 更好的扩展性，便于添加新的平台支持
