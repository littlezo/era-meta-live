## 修复服务调用失败问题

### 问题分析

1. **watch.rs中live_status变量警告**
   - **文件**: `src-tauri/src/watch.rs:105:43`
   - **问题**: 变量 `live_status` 初始值未被读取
   - **警告**: `value assigned to live_status is never read`

2. **Douyin平台注册失败**
   - **文件**: `src-tauri/src/platform_commands.rs`
   - **问题**: 调用平台工厂时，Douyin平台未注册
   - **错误**: `Failed to create platform instance for Douyin: Unsupported operation: Platform Douyin not registered`

### 修复方案

#### 1. 修复live_status变量警告

**修改文件**: `src-tauri/src/watch.rs`
**修改内容**: 移除变量初始赋值，仅声明变量类型

```rust
// 原代码
let mut live_status = "UNKNOWN".to_string();

// 修改后
let mut live_status: String;
```

#### 2. 修复Douyin平台注册失败

**修改文件**: `src-tauri/src/platform_commands.rs`
**修改内容**:

1. **添加初始化和注册代码**:
   - 在模块开头导入 `init_global_platform_factory` 和 `register_all_platforms`
   - 创建 `init_platforms` 函数，用于初始化平台工厂和注册所有平台
   - 在每个命令函数中调用 `init_platforms` 确保平台已注册

2. **修改后的代码结构**:
   ```rust
   // 导入新增的函数
   use platforms::{PlatformType, PlatformConfig, get_global_platform_factory, init_global_platform_factory, register_all_platforms};
   
   // 初始化平台工厂和注册所有平台
   async fn init_platforms() {
       static INITIALIZED: std::sync::OnceLock<bool> = std::sync::OnceLock::new();
       INITIALIZED.get_or_init(|| {
           tokio::spawn(async {
               init_global_platform_factory();
               if let Err(e) = register_all_platforms().await {
                   error!("Failed to register all platforms: {:?}", e);
               }
           });
           true
       });
   }
   
   // 在每个命令函数中调用初始化函数
   #[tauri::command]
   pub async fn fetch_live_list(
       platform: String,
       category_id: Option<String>,
       page: Option<u32>,
       page_size: Option<u32>,
   ) -> Result<serde_json::Value, String> {
       // 确保平台已注册
       init_platforms().await;
       
       // 原函数逻辑...
   }
   ```

### 设计特点

1. **延迟初始化**: 平台只在需要时注册
2. **线程安全**: 使用OnceLock确保只初始化一次
3. **自动化**: 开发者无需手动调用注册函数
4. **向后兼容**: 不影响现有代码逻辑
5. **高效**: 注册过程异步执行，不阻塞主线程
