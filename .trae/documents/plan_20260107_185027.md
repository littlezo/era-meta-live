## 修复 send_follow_list 命令缺少 room_id 字段问题

### 问题分析
根据错误信息和代码检查，发现 Tauri 2.x 会自动将前端传递的 camelCase 参数名转换为后端的 snake_case 参数名，但这个转换只应用于顶层参数，而不应用于嵌套对象中的字段。

前端在映射 `followList` 数组时使用了 snake_case 字段名（如 `room_id`、`streamer_id`、`avatar_url`），而 Tauri 2.x 期望前端传递 camelCase 字段名，导致后端无法正确解析 `room_id` 字段。

### 修复方案
修改 `platformApiService.ts` 文件中的 `sendFollowList` 方法，将映射后的对象字段名从 snake_case 改为 camelCase：

```typescript
// 修改前
await invoke<void>('send_follow_list', {
  followList: followList.map(streamer => ({
    platform: streamer.platform,
    room_id: streamer.roomId,
    streamer_id: streamer.id,
    nickname: streamer.nickname,
    avatar_url: streamer.avatarUrl
  }))
});

// 修改后
await invoke<void>('send_follow_list', {
  followList: followList.map(streamer => ({
    platform: streamer.platform,
    roomId: streamer.roomId,
    streamerId: streamer.id,
    nickname: streamer.nickname,
    avatarUrl: streamer.avatarUrl
  }))
});
```

### 验证方法
1. 编译项目，确保没有类型错误
2. 运行应用，检查是否还有 "missing field `room_id`" 错误
3. 确认关注列表能够成功发送到后端
