## 修复 send_follow_list 命令缺少 room_id 字段问题

### 问题分析
根据错误信息和代码检查，发现问题在于 Tauri 2.x 会自动将顶层参数名从 camelCase 转换为 snake_case，但不会自动转换嵌套对象中的字段名。前端已经使用 camelCase 字段名（如 `roomId`），但后端 `FrontendFollowedStreamer` 结构体期望接收 snake_case 字段名（如 `room_id`），导致字段匹配失败。

### 修复方案
修改后端 `platform_commands.rs` 文件中的 `FrontendFollowedStreamer` 结构体，添加 `#[serde(rename_all = "camelCase")]` 属性，这样 serde 就会自动将 camelCase 字段名转换为 snake_case：

```rust
// 修改前
#[derive(Debug, Deserialize)]
pub struct FrontendFollowedStreamer {
    pub platform: String,
    pub room_id: String,
    pub streamer_id: String,
    pub nickname: String,
    pub avatar_url: String,
}

// 修改后
#[derive(Debug, Deserialize)]
#[serde(rename_all = "camelCase")]
pub struct FrontendFollowedStreamer {
    pub platform: String,
    pub room_id: String,
    pub streamer_id: String,
    pub nickname: String,
    pub avatar_url: String,
}
```

### 验证方法
1. 编译 Rust 后端，确保没有编译错误
2. 运行应用，检查是否还有 "missing field `room_id`" 错误
3. 确认关注列表能够成功发送到后端
