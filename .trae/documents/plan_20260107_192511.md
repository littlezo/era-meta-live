## 修复 send_follow_list 命令参数名不匹配问题

### 问题分析
根据错误信息和 Tauri 2.x 文档，发现了问题的根本原因：

1. **错误信息解析**："invalid args `followList` for command `send_follow_list`: missing field `roomId`"
   - 命令 `send_follow_list` 收到了参数 `followList`
   - 但 Tauri 2.x 无法将其正确映射到后端的 `follow_list` 参数
   - 导致 Tauri 尝试将整个参数对象作为 `follow_list` 参数的值
   - 进而尝试将对象 `{ followList: [...] }` 解析为 `Vec<FrontendFollowedStreamer>`
   - 失败后产生了混淆的错误信息

2. **Tauri 2.x 参数转换规则**：
   - 命令名会自动从 camelCase 转换为 snake_case（如 `sendFollowList` → `send_follow_list`）
   - **但参数名不会自动转换**，必须完全匹配

### 修复方案
修改前端 `platformApiService.ts` 文件中的 `sendFollowList` 方法，将参数名从 `followList` 改为 `follow_list`：

```typescript
// 修改前
await invoke<void>('send_follow_list', {
  followList: followList.map(streamer => ({
    platform: streamer.platform,
    roomId: streamer.roomId,
    streamerId: streamer.id,
    nickname: streamer.nickname,
    avatarUrl: streamer.avatarUrl
  }))
});

// 修改后
await invoke<void>('send_follow_list', {
  follow_list: followList.map(streamer => ({
    platform: streamer.platform,
    roomId: streamer.roomId,
    streamerId: streamer.id,
    nickname: streamer.nickname,
    avatarUrl: streamer.avatarUrl
  }))
});
```

### 验证方法
1. 编译前端项目，确保没有类型错误
2. 运行应用，检查是否还有 "missing field `roomId`" 错误
3. 确认关注列表能够成功发送到后端
